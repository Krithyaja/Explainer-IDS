What is Iterative Deepening Search (IDS)?

Iterative Deepening Search (IDS)—also known as Iterative Deepening Depth-First Search (IDDFS)—is an uninformed search algorithm that combines the memory efficiency of Depth-First Search (DFS) with the completeness and optimality of Breadth-First Search (BFS).

IDS operates by running repeated Depth-First Searches with gradually increasing depth limits ($L = 0, 1, 2, 3, \dots$). It halts as soon as it discovers a target goal node at the shallowest depth.

Algorithm Comparison Matrix

Algorithm Time Complexity Space Complexity Complete? Optimal?
Breadth-First Search (BFS) O(b^d) O(b^d) (High RAM) Yes Yes (unit costs)
Depth-First Search (DFS) O(b^m) O(b · m) (Low RAM) No (infinite loops) No
Iterative Deepening (IDS) O(b^d) O(b · d) (Low RAM) Yes Yes (unit costs)

Why isn't re-visiting nodes too wasteful?

In an exponential search tree, the vast majority of nodes reside at the bottom level. Re-generating upper nodes incurs minimal overhead. For $b=10$ and $d=5$:

N(BFS) = 1 + 10 + 100 + 1000 + 10000 = 11,111
N(IDS) = 5(1) + 4(10) + 3(100) + 2(1000) + 1(10000) = 12,345
Overhead ≈ 11% extra node visits!

Key Takeaways

  • Combines BFS completeness with DFS linear space requirements.
  • Ideal for trees with large search depth or unknown solution depths.
  • Preferred method when search space is huge and memory is bounded.
