# 🌳 Iterative Deepening Search (IDS) Explainer

An interactive, visual educational web application for exploring **Iterative Deepening Search (IDS)** / **IDDFS**.

## ✨ Features
- **Interactive Tree Canvas**: Dynamic binary and ternary trees up to Depth 4.
- **Full Control Panel**: Step-by-step playback, speed control, target node selection, and depth limit visualization.
- **Full-Screen Viewport**: Top-right play controls for maximum canvas viewing.
- **AI-Powered Q&A Assistant Bot**: Instant answers to student doubts regarding space complexity $O(b \cdot d)$, time complexity $O(b^d)$, and comparisons with BFS/DFS.
- **Practice & Quiz Mode**: Interactive problem generator to test manual execution skills.
